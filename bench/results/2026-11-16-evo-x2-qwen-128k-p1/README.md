## 測定ツールの誤判定と修正範囲

測定ツールは、Fused を無効にした C0 が FP16 を選ぶと想定していました。今回のビルドでは、この想定が誤っていました。MMQ がないビルドでは、未設定の `STRATA_EXPERT_I8` が有効として扱われ、C0 は別の own-INT8 経路を選びました。

修正後は、固定したソースとビルド条件、実バイナリの hash、プロセスの引数、環境変数の存在・不在、起動回数、通常ログの経路情報を組み合わせて判定します。`STRATA_EXPERT_I8` を実際に確認していない古い記録を、後から確認済みにはしていません。最初の中止試験の値も、今回の6回には含めていません。

C0 では48層の own-INT8 選択計画と native-fused 分岐への進入記録0件、C1/B1 では48層の native-fused 選択計画と分岐への進入記録1件を確認しました。ただし、選択計画や分岐への進入記録は GPU カーネルの起動トレースではありません。全層・全呼び出しで実際に起動したカーネルを証明するものではありません。
